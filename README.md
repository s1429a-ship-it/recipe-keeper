# Recipe Keeper

Recipe Keeper は、ブラウザだけで使える 1 ファイル構成のレシピ管理アプリです。`index.html` を開くだけで、レシピの保存・検索・編集・削除、カテゴリ分類、タグ管理、冷蔵庫の材料からの検索、JSON バックアップ / 復元ができます。

## 使い方

1. このリポジトリを取得します。
2. `index.html` をブラウザで開きます。
3. レシピ名、カテゴリ、タグ、材料、作り方、メモを入力して「保存」を押します。

データはブラウザの LocalStorage に保存されます。別ブラウザや別端末へ移す場合は「JSONバックアップ」でエクスポートし、「JSON復元」でインポートしてください。

## 主な機能

- レシピ保存
- レシピ検索（料理名・材料・タグ・メモが対象）
- レシピ編集
- レシピ削除
- カテゴリ分類
- タグ管理
- 冷蔵庫の材料から検索
- JSON バックアップ
- JSON 復元
- スマホ対応のレスポンシブ UI

## ファイル構成

```text
.
├── index.html
└── README.md
```

## 開発メモ

外部ライブラリやビルド工程は不要です。変更後はブラウザで `index.html` を開いて動作を確認してください。
